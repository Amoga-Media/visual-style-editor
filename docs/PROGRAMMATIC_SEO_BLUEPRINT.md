## 1. Executive Summary & Strategy

Visual Style Editor occupies a unique position in the developer tooling and design landscape:
- **Zero-Backend / 100% Client-Side**: No file uploads, no cloud databases, zero telemetry leakage.
- **Surgical AST Splicing**: Modifies only targeted HTML AST attributes and Tailwind classes without reformatting comments, script tags (GSAP, Swiper), or CSS variables.
- **Direct Local Disk Sync**: Powered by the Chromium W3C File System Access API (`showOpenFilePicker`), enabling instant two-way file persistence.
- **Free & Open-Source (MIT)**: Zero paywalls, zero subscription tiers, zero vendor lock-in.

This **Programmatic SEO & Competitor Displacement Blueprint** defines the programmatic route expansion strategy across three core pillars:
1. **Competitor Displacement (`/vs/*`)**: Intercept high-intent queries comparing Visual Style Editor against paid, proprietary, or cloud-locked tools (Webflow, Framer, Windframe) and AI code assistants (Cursor, v0).
2. **Ecosystem & Workflow Landing Pages (`/for/*`)**: Capture intent around specific developer workflows, frameworks, and AI artifact polish (Tailwind v4, Cursor, v0, Claude Artifacts).
3. **Template Taxonomy Matrix (`/templates/*`)**: Scalable programmatic indexation of starter kits, landing pages, dashboards, and responsive component libraries.

## 7. Performance & Crawl Budget Protection

When generating programmatic landing pages, maintain strict hygiene:
1. **SSG Generation**: Every page is pre-rendered at build time with 0ms runtime server execution.
2. **Canonical Consistency**: Every programmatic route must specify an exact, canonical self-referential URL without trailing slash mismatches.
3. **Structured Data Validation**: All pages must pass Google Rich Results testing with valid `BreadcrumbList`, `WebPage`, and `@graph` linkages.
4. **Link Internal Architecture**: All programmatic comparison and template pages must be discoverable via HTML sitemaps and contextual in-content cross-links to prevent orphan pages.
