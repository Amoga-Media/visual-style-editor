POST /v1/splice-classes

Surgically Splice Class Attributes

Locates the precise start and end character offsets of a node's class attribute and splices replacement classes without re-serializing adjacent DOM elements.

Example Request (TypeScript)
import { spliceClasses } from '@vse/ast-core';
// Returns updated string without touching adjacent comments
const modifiedHtml = spliceClasses(rawHtml, {
targetNodeId: 'hero-title-node',
newClasses: 'text-5xl font-black text-purple-400',
preserveIndentation: true,
});
Input Parameters
Param Type Description
rawHtml string The complete original HTML document string.
newClasses string The synthesized idiomatic Tailwind utility class string.
preserveIndentation boolean Preserves leading tabs, spaces, and line wraps. Defaults to true.
